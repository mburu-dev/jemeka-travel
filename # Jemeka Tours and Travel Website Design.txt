### 1.2 UX & Design Insights from Leaders

**Experience-First Visual Storytelling**
Modern travel websites use immersive imagery, video backgrounds, and carefully crafted layouts to make users "feel the destination before booking," while keeping pricing and actions clearly visible .

**Trust-Centered Design Systems**
Top performers highlight reviews, ratings, guarantees, and transparent pricing earlier in the journey. Modern trust design looks native—not like bolted-on badges from 2012 .

**Mobile-First Booking Dominance**
Over 60% of travel booking sessions are completed via mobile devices, yet desktop users spend 6m 59s vs. 3m 30s on mobile. Mobile-first design is non-negotiable .

**Speed as a Conversion Feature**
A website loading in 1 second achieves 2.5x higher conversion rate than one loading in 5 seconds. Travel sites in the top 20% load under 2.2 seconds; mobile loads ~70.9% slower than desktop .

**3.3 Security Protocols**

- **Data Encryption**: AES-256 for data at rest, TLS 1.3 for data in transit
- **Authentication**: JWT with refresh token rotation, HTTP-only cookies, CSRF protection
- **Payment Security**: PCI-DSS SAQ-A compliance via tokenization (Stripe Elements/PayPal SDK); no card data touches Jemeka servers
- **Input Validation**: Zod schema validation on all API inputs; parameterized queries (SQL injection prevention)
- **XSS Protection**: Content Security Policy headers, React automatic escaping, DOMPurify for rich text
- **Rate Limiting**: express-rate-limit (100 req/min per IP), stricter limits on auth endpoints
- **Dependency Scanning**: Snyk CLI in CI/CD pipeline
- **Backup Strategy**: Daily automated PostgreSQL dumps to MinIO, 30-day retention

**3.4 Scalability Plan**

- **Horizontal Scaling**: Docker Swarm/Kubernetes for container orchestration
- **Database**: Read replicas for search queries; connection pooling via PgBouncer
- **Caching**: Redis for session storage, query result caching, and rate limiting
- **CDN**: Nginx caching layer + Cloudflare (free tier) for global static asset delivery
- **Search**: Meilisearch horizontal scaling via master/slave configuration

### Step 3.4: Security Implementation
- Helmet.js for security headers (CSP, HSTS, X-Frame-Options)
- express-rate-limit: 100 req/min general, 10 req/min auth
- CORS: Whitelist only production domains
- Input sanitization: DOMPurify for any HTML content
- SQL injection prevention: Prisma parameterized queries exclusively
- XSS prevention: CSP headers, React auto-escaping
- JWT: RS256 algorithm, 15min access / 7day refresh tokens, HTTP-only cookies
- Password hashing: bcrypt with salt rounds 12
- Audit logging: All auth events, booking modifications, payment attempts
